# 面向人工智能方向的毕业论文题目参考

以下题目聚焦本项目的核心能力：基于 PyQt5 与 OpenCV 的单摄像头人脸检测/识别、陌生人模糊处理、实时参数调节与本地登录安全。可根据研究重点（算法、系统工程、隐私保护、交互设计等）进行微调。

1. **《基于单摄像头的人脸识别与隐私模糊系统的实时优化研究》**  
   探索轻量化检测/识别模型在桌面端的实时优化策略，并评估模糊强度与识别阈值的动态调节效果。
2. **《面向本地安全登录的人脸识别桌面应用设计与实现》**  
   研究账号密码与人脸双因素验证的可行性，重点分析本地配置管理与人脸库维护策略。
3. **《单路视频源的实时人脸隐私保护：自适应模糊与阈值控制方法》**  
   聚焦陌生人高斯模糊的自适应算法，结合识别阈值调节对误检/漏检的影响进行实验对比。
4. **《基于 PyQt5 的人脸识别监控界面交互设计与用户体验评估》**  
   面向深色主题、渐变按钮、圆角卡片式布局等 UI 特性，评估控制面板交互与状态可视化对用户体验的影响。
5. **《单摄像头人脸识别系统的可配置化部署与运维实践》**  
   总结配置文件驱动的摄像头与模型参数管理方式，讨论日志与监控面板在可维护性方面的作用。

> 提示：选题时可结合数据集选择、模型蒸馏/量化、隐私保护合规性或系统扩展性等角度，提升论文的研究深度与工程落地价值。
