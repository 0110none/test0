# 单摄像头人脸识别与隐私保护系统设计说明（基于现有代码）

## （一）设计任务
1. **场景分析与目标明确**：结合现有项目“单摄像头人脸识别与隐私保护系统”，聚焦单路视频输入的实时人脸检测、识别与陌生人模糊处理可行性，明确以本地化部署、隐私保护和桌面级易用性为核心目标。
2. **架构设计**：绘制单源管线的整体架构，包括登录与账号配置（`config/user_config.json`）、单摄像头采集（`config/camera_config.yaml` + `core/camera_manager.py`）、人脸检测与识别（InsightFace，`core/face_detection.py`）、隐私模糊处理与 GUI 展示（`ui/main_window.py`）、人脸库管理对话框（`ui/face_manager.py`）、日志记录与目录管理（`logs/`、`data/known_faces/`）。
3. **功能实现**：完成单源视频流接入（USB/RTSP/文件由 `source` 字段配置）、深度学习人脸检测与特征匹配、已知人脸清晰展示与陌生人高斯模糊处理；在 PyQt5 主界面中提供摄像头启停、识别阈值与模糊强度/形状调节，以及人脸库的导入、添加、更新、删除等操作。
4. **能力验证**：围绕单摄像头同步处理能力、人脸检测/识别精度、模糊效果与性能、GUI 响应性（启动、全屏切换、状态栏更新）、登录与密码修改可靠性、日志输出完整性进行测试，确保满足桌面级实时监控与隐私保护需求。

## （二）系统设计要求
1. **单源视频处理功能**：支持通过配置文件指定 1 路视频源（摄像头序号、RTSP 地址或视频文件），实时解码与展示。对画面中的人脸进行检测与识别：已知人脸显示姓名与置信度，陌生人自动套用可调节范围与形状的高斯模糊，并在状态栏/状态面板展示当前检测数量、模糊数量及摄像头健康状态。
2. **用户交互功能**：PyQt5 桌面界面提供登录认证与密码修改、摄像头启动/停止、识别阈值滑杆、模糊强度滑杆、矩形/椭圆模糊形状切换、全屏切换等控制；人脸管理对话框支持从图片导入、添加新脸、更新已有脸（重命名与替换图片）、删除人脸并实时刷新识别库。
3. **提示与可靠性保障**：通过状态面板对摄像头延迟、信号丢失等异常进行文字提示，结合日志文件记录运行与错误信息；人脸库、日志与配置文件均落盘存储，确保退出后数据与配置可持续复用。当前实现未包含声音、弹窗告警或 Telegram 推送，重点保障本地端的稳定运行与隐私处理效果。
